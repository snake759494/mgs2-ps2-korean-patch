# 글꼴 출처

- 게임 글꼴(24×24 2bpp)의 한글 1,182자: NanumSquare Neo dEb(ExtraBold) 23px, 4배 확대 렌더 후 축소해 4단계 농도로 변환 (`tools/hfont.py`). 원본의 굵은 고딕과 비교해 선택.
- 그림 속 글자(지역명 카드·튜토리얼·크레디트 등): NanumSquare Neo cBd(Bold), 원본 팔레트 인덱스로 양자화 (`tools/texpatch.py`).
