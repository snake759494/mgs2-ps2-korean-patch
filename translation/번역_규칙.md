# MGS2 한글패치 번역 규칙

## 작업 방식
- 외부 번역기·번역 서비스 사용 금지. 직접 읽고 직접 번역한다.
- 원문은 OCR로 복원된 일본어라 드물게 틀린 한자가 섞여 있다. 문맥으로 바로잡아 번역한다.
- 입력 형식: `@번호 [출처]` 다음 줄부터 원문. 출력은 JSON 객체 `{"번호": "번역문", ...}` (번호는 문자열 키).
- 모든 항목을 빠짐없이 번역한다. 원문이 비었거나 기호뿐이면 그대로 둔다.

## 표기 형식 (반드시 지킬 것)
- 사용 가능 문자: 한글 완성형, 숫자, ASCII 영문/기호(! ? . , : ; ' " ( ) - + / % & ~ * # 제외), 그리고 `… ― 「 」 『 』 ○ △ □ × “ ” ‘ ’ ・` 만 사용.
  - `#` 은 엔진 제어문자라 절대 쓰지 않는다. `{` `}` 는 루비 표기에만 쓴다.
  - 그 밖의 특수문자(—, ·, ♪, ★, 전각 숫자 등)는 쓰지 않는다. 가운뎃점은 `・`, 말줄임은 `……` 를 쓴다.
- 문장부호는 ASCII `. , ! ?` 를 쓴다(일본어 `。、！？` 대신).
- 루비 `{본문:루비}` : 원문에 루비가 있으면 같은 형식으로 남긴다. 버튼 표기 `{□:무기}` 처럼 버튼 기호는 그대로 두고 루비만 번역한다. 원어 발음 루비(예: 무인정찰기→UAV)는 `{무인 정찰기:UAV}` 처럼 유지한다. 루비 본문은 짧게.
- [codec] 줄바꿈은 자동으로 다시 맞추므로 번역문에 줄바꿈을 넣지 않는다(한 문장으로). 단, 한 화면은 최대 3줄(한 줄 약 19자, 공백 포함 약 55자 이내)이므로 원문보다 길게 늘이지 말고 간결하게.
- [demo]/[vox] 자막: `|` 는 줄바꿈. 번역문에서는 `|` 없이 한 덩어리로 써도 자동으로 2줄 이내로 맞춘다. 최대 2줄(한 줄 약 20자, 전체 약 40자). 넘치면 줄여라.
- [stage] 문자열(아이템 설명, 메뉴, 지역명 등): 원문의 `|` 와 줄바꿈 구조를 그대로 유지하고, 각 줄은 한글 기준 20자 이내. 첫 줄이 아이템 이름이면 이름만 짧게.
- 숫자·영문 고유명(USP, SOCOM, M9, RAY 등)은 그대로.

## 문체
- 대사는 자연스러운 한국어 구어체. 직역투 금지.
- 스네이크: 무뚝뚝한 반말. 오타콘: 친근한 반말. 대령(→라이덴): 명령조 반말. 로즈→라이덴: 다정한 반말. 라이덴→대령: 존댓말(대령님). 라이덴→로즈: 반말.
- 병사·적: 거친 반말. 시스템 메시지·설명문: 합니다체.
- 게임 내 존칭: 大佐=대령, 隊長=대장.
